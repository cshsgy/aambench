\section{Conventions}
Unit sphere unless stated; rotation vector $\bm\Omega=\Omega\hat z$; $s=r\cos\phi$ distance to the axis;
$\psi=\Omega s^2$ planetary AAM per unit mass; $L=s(u+\Omega s)$ absolute AAM per unit mass.
Discrete: $V_c$ cell volume, $\bm K_c$ unit zonal direction, $G$ linear map from cell velocities to
face mass flux, $C$ linear Coriolis operator. Every numerical claim states norm, state, grid sequence,
run length and the commit of the script.
